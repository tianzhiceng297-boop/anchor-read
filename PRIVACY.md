# AnchorRead Privacy Policy

**Effective Date: June 2026**

## Data Collection

AnchorRead does **not** collect, store, or transmit any personal data.

## What AnchorRead Does

- Modifies the visual appearance of text on web pages you visit by bolding the first portion of each word
- All text processing happens **locally in your browser**
- No data is sent to any external server

## Permissions

AnchorRead requires the following permissions:

- **Read and change all your data on all websites**: This permission allows the extension to access the text content on web pages you visit so it can apply the bold formatting. The extension does not read, collect, or transmit any of this data.

## Data Storage

AnchorRead uses Chrome's local storage to save your preferences:

- **Enabled/disabled state** — Whether the extension is active
- **Bold ratio** — Your preferred bold intensity (10%-90%)

This data is stored **only on your device** and is never transmitted anywhere.

## Third-Party Services

AnchorRead does not use any third-party services, analytics, or tracking.

## Open Source

AnchorRead is fully open source. You can verify these claims by reviewing the source code at: [https://github.com/tianzhiceng297-boop/anchor-read](https://github.com/tianzhiceng297-boop/anchor-read)
