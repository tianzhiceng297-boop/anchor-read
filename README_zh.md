# AnchorRead

中文 | [English](README.md)

免费开源的阅读加速器 Chrome 浏览器插件。通过加粗单词的前半部分来创建注视锚点，引导眼球平滑扫过文本。

## 什么是锚点阅读？

锚点阅读（Fixation Reading）是一种阅读辅助技术，通过加粗每个单词的前半部分来创建人工注视点，引导眼球平滑扫过文本，可能提升阅读速度和专注度。AnchorRead 是这种文本格式化方式的免费开源实现。

## 功能特性

- **一键开关** — 在任意页面上即时启用/关闭
- **Fixation Boundary Table 算法** — 纯数学查表，不依赖语言，快速稳定
- **动态内容支持** — 自动转换页面加载后新增的文本（SPA 应用、无限滚动）
- **轻量级** — 零依赖，总计约 8KB
- **隐私优先** — 不收集数据，不发网络请求，不需要账号
- **永久免费** — 基于 MIT 开源协议

从没安装过浏览器插件？没关系，跟着下面一步步来：

#### 第 1 步 — 下载插件文件

将源码下载为 ZIP 压缩包：

1. 打开 [https://github.com/tianzhiceng297-boop/anchor-read](https://github.com/tianzhiceng297-boop/anchor-read)
2. 点击页面顶部绿色的 **"Code"** 按钮
3. 选择 **"Download ZIP"**
4. 将下载的 ZIP 文件解压到电脑上的任意文件夹

> 解压后的文件夹里应该包含 `manifest.json`、`content.js`、`popup.html` 等文件。

#### 第 2 步 — 打开 Chrome 扩展管理页面

1. 打开 Google Chrome 浏览器（或其他基于 Chromium 的浏览器，如 Edge、Brave）
2. 在地址栏输入 `chrome://extensions/` 并按回车
3. 也可以通过菜单操作：点击右上角 **菜单图标**（三个点 ⋮）→ **扩展程序** → **管理扩展程序**

#### 第 3 步 — 开启开发者模式

1. 在扩展管理页面，找到 **右上角** 的 **"开发者模式"** 开关
2. 将其 **打开** — 这允许你从本地加载扩展
3. 不用担心，这只是让 Chrome 允许你加载自己的扩展程序，很安全

#### 第 4 步 — 加载插件

1. 点击页面 **左上角** 出现的 **"加载已解压的扩展程序"** 按钮
2. 在弹出的文件选择器中，找到你在第 1 步解压的 `anchor-read` 文件夹
3. 选中该文件夹并点击 **"选择文件夹"**

> **注意**：请选择包含 `manifest.json` 的那个文件夹，不要选它的上级目录。

#### 第 5 步 — 确认安装成功

- 扩展列表中应该出现名为 **"AnchorRead"** 的扩展
- Chrome 工具栏会出现一个拼图 🧩 图标 — 点击它，然后将 AnchorRead 固定到工具栏
- 你应该在工具栏看到 AnchorRead 的图标（蓝色圆角方形，上面有一个 "A"）

#### Microsoft Edge 用户

Edge 也使用 Chromium 内核，同样可以安装 Chrome 扩展：

1. 在地址栏输入 `edge://extensions/`
2. 开启 **开发者模式**（在左侧边栏）
3. 点击 **"加载已解压的扩展"**，选择 `anchor-read` 文件夹

## 使用方法

1. 点击浏览器工具栏中的 **AnchorRead** 图标（如果看不到，先点击 🧩 拼图图标找找）
2. 切换开关来启用/关闭当前页面
3. **首次使用提醒**：如果页面尚未刷新，弹窗会提示"请刷新页面以激活"
4. 页面文本会即时转换 — 无需再次刷新
5. 设置自动保存，跨页面保持你的偏好

### 首次使用提醒

> ⚠️ **安装插件后，或在新标签页中第一次使用时，必须刷新一次页面** 才能让 AnchorRead 生效。弹窗中会显示提醒。

### 使用提示

- **某个页面不生效？** 部分页面（如 Chrome 应用商店本身）出于安全原因会限制扩展脚本运行
- **动态页面**：AnchorRead 会自动处理滚动加载内容的页面（如 Twitter、Reddit 等）
- **临时关闭**：只需把开关关掉 — 页面文本会立刻恢复原样

## 算法原理

AnchorRead 的核心是将每个单词在视觉上"切断"，在字母交界处制造一个**注视锚点（Fixation Anchor）**，让眼球扫视（saccade）时有一个明确的落点。

### 第一阶段：text-vide 边界表（Baseline）

使用 text-vide 验证过的 **Fixation Boundary Table（注视边界表）**，这是开源社区广泛采用的固定查表算法（fixationPoint=3，text-vide 默认值）。

**核心逻辑（反向减法）：**

1. 测量单词长度 `len`
2. 查边界表 `[0, 1, 2, 5, 7, 9, 11, 13, 15, 17, ...]`
3. 找到第一个 `>= len` 的边界值；其**索引** = 不加粗的尾部字符数
4. 加粗长度 = `len - 索引`（永远不加粗整个单词）

**示例：**

| 单词 | 长度 | 加粗长度 | 效果 |
|------|------|---------|------|
| cat | 3 | 1 | **c**at |
| hello | 5 | 3 | **hel**lo |
| reading | 7 | 4 | **read**ing |
| comprehensive | 13 | 7 | **compreh**ensive |

### 第二阶段：光学平衡调整（Optical Balance Adjustment）

边界表给出的是"数学中点"，但人眼感知的**视觉重心**并不等于几何中点。v1.2.6 引入光学平衡规则引擎，在边界表的基础上做二次调整。

**为什么需要光学平衡？**

| 问题 | 数学断点 | 视觉感受 |
|------|---------|---------|
| `water` | `wat\|er` | `t` 是轻字母，终点"站不住" |
| `develop` | `devel\|op` | `p` 是下伸字母，天然锚点，应利用 |
| `icon` | `ic\|on` | `c` 向右开口，与 `o` 粘连，应提前切断 |

**5 个优先级的 optical 规则：**

| 优先级 | 规则 | 示例 |
|--------|------|------|
| 1 | **单词特例表**（手工标定的最优断点） | `water` → `wate\|r`，`develop` → `devel\|op` |
| 2 | **音节/词根边界** | `action` → `ac\|tion`，`running` → `runn\|ing` |
| 3 | **视觉重心偏左**（几何中点再左移 ~1/6 词长） | 7 字母词的中点=4，光学终点=3 |
| 4 | **避免重-轻-重跳跃** | 不以 `i`/`l`/`t` 这种视觉重量轻的字母做终点 |
| 5 | **终点偏好下伸/上伸字母** | `g`/`j`/`p`/`q`/`y` 的下伸钩能"托住"视觉重量 |

**融合策略：** 边界表给出 baseline，光学规则给出建议值；两者偏差 ≤2 时采纳光学值，否则保留 baseline（防止过度调整）。

### 实词过滤层（Content Word Filter）

v1.2.5 引入，可选开启：功能词（the/to/of/and/be/have/do 等 ~150 个）不做加粗，只加粗有实际语义的实词（名词/动词/形容词/副词）。减少无意义加粗，降低视觉噪音。
